# セキュリティ観点: server / client 境界

対象: 全リポジトリ（フレームワーク非依存の土台。バージョンの前提を持たない）

変更ファイルの中で「サーバーで動くコード」と「ブラウザへ配られるコード」を取り違えると、評価が丸ごと逆になる。ここでは境界の確定手順と、境界をまたぐときに壊れやすい点を扱う。

## 拡張子で判断しない

`.ts` / `.tsx` はどこで動くかを示さない。次はいずれもサーバーで動くが、コンポーネントと同じ拡張子・同じディレクトリに置かれる。

- ルートファイルが公開するデータ取得・更新関数（React Router の `loader` / `action` など）
- Server Component、`'use server'` を付けた関数（Next.js App Router）
- ミドルウェア、Worker のエントリポイント

汎用のセキュリティレビューは「`.tsx` はクライアントコードだから認可はバックエンドの責務」という前提を持つことがある（組み込みの `/security-review` はこれを明文化している）。上のファイル群ではその前提が逆転し、**免責してはいけないコードが免責される**。レビューでは最初に「この関数はどこで動くか」を確定させてから読む。

## 境界を確定する手がかり

| 手がかり | 分かること |
|---|---|
| フレームワーク設定の `ssr` / 出力モード | リクエスト時にサーバーが動くのか、ビルド時のみか |
| `prerender` / SSG の対象 | ビルド時に確定し、全閲覧者へ同じ内容が配られる |
| ビルドツールの `define` / 環境変数の公開接頭辞 | 値がバンドルへ文字列として埋め込まれる |
| `'use client'` / `'use server'` / `*.server.*` などの規約 | 明示された境界 |

同じフレームワークでも設定で結論が変わる。SSR 有効なら `loader` はリクエスト時に動く公開エンドポイントだが、`ssr: false` + `prerender` ならビルド時にしか動かず、論点は「認可」ではなく「バンドルと生成済み HTML に何を埋め込んだか」へ移る。**フレームワーク名だけで判断せず、必ず設定を確認する。**

## 境界をまたぐときの確認項目

以下は原則。**該当するフレームワーク別ファイル（`nextjs.md` / `react-router.md` など）がある場合、具体的な機構と見つけ方はそちらに書いてある。両方を読んだときは指摘を片方にまとめ、同じ論点を二重に出さない。** 該当ファイルが無いリポジトリでは、この節だけで判断する。

### 1. ビルド時にインライン化される値に機密を混ぜない

ビルドツールの `define`、`NEXT_PUBLIC_` / `VITE_` などの公開接頭辞を持つ環境変数は、**バンドルに文字列として埋め込まれて配布される**。実行時に参照されるサーバー側の設定と見た目が変わらないため、機密を1行足しても通常の設定変更にしか見えない。ハードコードされた秘密ではないので、汎用スキャナも反応しない。

差分での見つけ方: これらに**行が追加されていたら、その値が公開されてよいか**を必ず確認する。API のベース URL や解析 ID は問題ないが、トークン・API キー・認証情報は該当しない。

### 2. サーバーで取得したデータは描画しなくてもクライアントへ配られる

戻り値や境界をまたぐ props はシリアライズされて渡る（RSC ペイロード、ルートのデータレスポンス、埋め込み JSON など）。レコードをそのまま返すと画面に出していないフィールドまで配布される。**「レンダリングしていないから安全」は成り立たない。**

### 3. データ取得・更新関数は公開エンドポイントとして扱う

サーバー側のデータ取得・更新関数には、フレームワークが URL や ID を割り当てて外部から直接呼べるようにする。**呼び出し側の画面での出し分けは認可にならない。** 認可は各関数の内部に置く。

### 4. ミドルウェア単独の認可に依存しない

ミドルウェアでの一括認可は、フレームワーク側の実装不備で迂回されると全経路が同時に破られる。ミドルウェアは前段のフィルタとして使い、**保護対象のリソース側にも認可を置く**。

### 5. 静的生成されるページに閲覧者ごとに変わるデータを載せない

`prerender` / SSG の対象ページはビルド時に内容が固定され、**全閲覧者へ同じ HTML が配られる**。閲覧者に応じて出し分けるつもりのデータをここに置くと、ビルド時の値が無条件に公開される。
